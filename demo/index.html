NetScope — a live sample evidence report

NetScope is an internet-experience diagnostic for your terminal: seven probes, a 0–100 experience score, and evidence reports that answer whether the problem is your Wi-Fi, your ISP, or the service — 1,000 tests, fully offline.

Open the live sample report → Read the code
Why is the score in this sample low (29/100)?

Because this report was generated on a locked-down CI VM — no ICMP raw sockets, a containerized gateway, proxied egress. Half the probes genuinely fail there, and NetScope refuses to fake a "healthy": every failed probe stays in the report as evidence, and the score drops accordingly. That is the product's core honesty rule — "missing" is never reported as "healthy" — doing exactly what it promises, under bad conditions. Run it on your own machine and the same probes tell you the truth about your network.

Run it on your machine

The report you just opened came from one command: netscope report --html report.html. Install from PyPI:

pip install netscope
netscope check github.com      # probe any target
netscope report --html report.html
